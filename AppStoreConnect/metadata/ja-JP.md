# HapTick App Store Metadata - ja

Name: HapTick

Subtitle:
iPhoneとWatchの触覚メトロノーム

Promotional Text:
iPhoneで繰り返す触覚シーケンスを作成。直接再生したり、Apple Watchに同期して単独で使える無音メトロノームに。

Description:
HapTickはiPhoneとApple Watchのための触覚タイマーと無音メトロノーム（metronome）です。

間隔やBPMを設定し、単一の触覚スタイルを選ぶか、最大64ステップのシーケンスを作成できます。各ステップは触覚スタイルの略称で表示されます。変更、移動、複製、削除して、シーケンス全体をループ再生できます。

iPhoneでHapTickを開いている間は直接触覚を再生できます。設定とシーケンスをApple Watchに同期することもできます。Watchは設定を保存し、単独でも使用できます。Digital Crownで間隔やBPMを調整し、リングをタップして開始・停止。手首を返すジェスチャも選べます。

速度の警告により、シーケンス内の各スタイルに適した間隔を選べます。

英語、簡体字・繁体字中国語、日本語、フランス語、スペイン語に対応。アカウント、広告、分析、音は不要です。

Keywords:
触覚,タイマー,メトロノーム,Watch,BPM,間隔,振動,リズム,シーケンス

What’s New:
触覚スタイルの略称を使ってシーケンスを作成し、ループ再生できます。iPhoneでの触覚再生とApple Watchへのシーケンス同期に対応。中国語、日本語、フランス語、スペイン語と地域に合わせた小数入力を追加しました。
