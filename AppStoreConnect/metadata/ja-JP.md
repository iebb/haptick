# HapTick App Store Metadata - ja-JP

Name: HapTick

Subtitle: Apple Watch用触覚タイマー

Promotional Text:
Apple Watchで繰り返し触覚パルスを再生。間隔やBPMはWatchでもiPhoneでも調整できます。

Description:
HapTickは、Apple Watch向けのシンプルな触覚タイマー兼metronomeです。

間隔またはBPMを設定し、Watchの触覚スタイルを選び、Watch上で直接スタート／ストップできます。iPhoneコンパニオンアプリでは、同じ設定を大きな画面で編集してApple Watchへ同期できます。

主な機能:
- 指定した間隔またはBPMでApple Watchの触覚を繰り返し再生
- 間隔モードとBPMモード
- 複数のWatch触覚スタイル
- フリップ操作によるスタート／ストップ
- iPhoneからApple Watchへ設定を同期
- 前回の設定を保存

音を出さずに、手首だけでmetronomeのようなリズムやタイミングを感じたい場面に向けたアプリです。
